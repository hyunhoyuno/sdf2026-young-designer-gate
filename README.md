# SDF 2026 영 디자이너 게이트 목업

서울디자인페스티벌 2026 영 디자이너 게이트 구조물(누리안 도면 2026.11.16 기준)을 3D로 보고, 벽 A–G 패널에 시안 이미지를 올려 확인하는 목업입니다.

- `index.html` — three.js 3D 뷰 (회전·확대·시점 버튼, 패널 이미지 올리기)
- `panels/A–G.jpg` — 인디자인 `SDF_현장제작물_1119_CMYK.indd` 65–71쪽(1/10) 내보내기

로컬에서 볼 때는 파일을 더블클릭하지 말고 간단한 서버로 여세요 (브라우저 보안 때문에 패널 이미지가 안 뜹니다).

```bash
python3 -m http.server 8000
```
